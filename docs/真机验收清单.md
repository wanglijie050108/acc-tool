# 真机验收清单 — 流水记账 v0.1.0

> **一句话说明**：这是给你在手机上实际验收用的清单。
> 从头到尾做一遍约 **15 分钟**（不含隔夜保活那项）。
> 每一项都有「怎么做」和「算通过的样子」，照着打勾即可。

**不需要下载任何软件。** 电脑上编译环境已装好，手机端也不用装任何东西。

## 一、把 App 装到手机上（二选一）

### 路线 A：数据线 + USB 调试（推荐，最快）

装好后我还能**直接看到手机上的崩溃日志**，出问题好定位。

1. **手机**：设置 → 关于手机 → 连续点「版本号」7 次 → 提示已进入开发者模式
2. **手机**：设置 → 系统 → 开发者选项 → 打开 **USB 调试**
3. 用**能传数据**的 USB 线连电脑（只能充电的线不行）
4. 手机弹「允许 USB 调试吗？」→ 勾「一律允许」→ 允许
5. 回来告诉我「连好了」，我用命令直接把 App 装进去

> 小米：开发者选项在「设置 → 更多设置 → 开发者选项」
> 华为/荣耀：设置 → 系统和更新 → 开发人员选项

### 路线 B：自己传文件装（不用数据线）

任选一种把 APK 弄到手机上：

- **微信**：电脑微信 → 文件传输助手 → 发文件 → 手机微信点开 → 右上角「用其他应用打开」
- **QQ**：我的电脑 → 发送文件到手机
- **数据线**：连电脑 → 把 APK 拷到手机 `Download` 文件夹 → 手机「文件管理」里点开
- **网盘**：上传后手机端下载

然后在手机上点这个文件 → 系统提示「未知来源」→ **允许** → 安装。

> ⚠️ 安装时如果提示「已有相同签名的应用」，先卸载旧版本再装。

### 阶段 2 — 三步授权（**最重要，不做完后面全是白测**）

在 **设置** 页里逐项做：

| # | 项目 | 怎么做 | 通过的样子 |
|---|---|---|---|
| 2.1 | **1. 通知使用权（必须）** | 点「去开启」→ 在列表里找到「流水记账」→ 打开开关 → 弹窗警告点「允许」 | 回到 App 后该项显示绿色 **已开启**，且**没有**黄色警告文字 |
| 2.2 | **2. 短信权限（推荐）** | 点「去开启」→ 允许「短信」权限 | 显示 **已开启** |
| 2.3 | **3. 后台运行（强烈建议）** | 点「去关闭」→ 弹窗选「允许」 | 显示 **已开启** |

**另加国产 ROM 必做一步**（不做，几小时后会被系统杀掉，漏记）：

| 品牌 | 操作 |
|---|---|
| 小米/红米 | 设置 → 应用设置 → 应用管理 → 流水记账 → 省电策略 → **无限制**；再到「最近任务」界面下拉这个 App → 点 🔒 加锁 |
| 华为/荣耀 | 设置 → 应用 → 应用启动管理 → 流水记账 → 关「自动管理」→ 手动管理三项**全开** |
| OPPO/一加 | 设置 → 电池 → 应用耗电管理 → 流水记账 → 允许**后台运行** |
| vivo | 设置 → 电池 → 后台高耗电 → 允许流水记账 |
| 三星 | 设置 → 电池 → 后台使用限制 → 加入「永不进入休眠的应用」 |

> ⚠️ 以后**不要在最近任务里划掉这个 App**，划掉 = 关掉监听。

> 若 2.1 显示 **「已授权·未连接」**：这就是掉线了，**退出设置页再进是没用的**（真机已实测）。
> 请到系统设置里把「通知使用权」开关**关掉再打开**（见 [真机验收记录](真机验收记录.md) 问题 1）。

### 阶段 3 — 离线自检（**不用花一分钱**）

**设置 → 解析测试**，把下面几种真实文本分别粘进去，点「测试识别」：

| # | 粘什么 | 通过的样子 |
|---|---|---|
| 3.1 | 一条**真实微信支付**通知原文 | ✅ 识别成功，金额正确，方向=支出，商户名正确 |
| 3.2 | 一条**真实支付宝**通知原文 | ✅ 同上 |
| 3.3 | 一条**银行扣款短信** | ✅ 识别成功，金额正确 |
| 3.4 | 一条**验证码**短信（如「验证码 123456」） | ⚠️ **未识别** —— 这是对的，证明不会误记 |

> **怎么拿到通知原文**：支付后下拉通知栏 → 长按那条通知 → 复制文本。
> 拿不到就截图发我，我来读。

> ❌ 3.1–3.3 显示「未识别」→ **把原文复制给我**，我加规则。
> ❌ 3.4 把验证码记成了流水 → 这是严重 bug，立刻告诉我。

### 阶段 4 — 真实抓取（花 0.01~0.1 元）

> ⚠️ **2026-10-14 真机验收的重要修正**：**微信/支付宝的「转账」通知里没有金额**
> （真机原文就是「[转账] 已被接收」），所以**给好友转账这条路验不出来**。
> 请用**扫码付款给商家**，或**银行卡消费**。

| # | 怎么做 | 通过的样子 |
|---|---|---|
| 4.1 | 用**主空间**的微信/支付宝**扫商家收款码**付 0.01 元，付完**立刻退出到桌面** | 回到 App 首页，**自动出现**一条 0.01 元支出 |
| 4.2 | 用**银行卡**消费一笔（该卡要开了短信提醒） | 自动出现一条，金额与短信一致 |
| 4.3 | 点开任意一条记录 | 弹窗底部能看到**原始文本**，内容与收到的通知/短信一致 |
| 4.4 | 看首页顶部汇总 | 「本月支出」「收入」「共 N 笔」和列表条数对得上 |

> 🚫 **不要用「给好友转账」来测** —— 那条通知里没有金额，本来就记不上。
> 🚫 **不要用「应用分身」里的微信/支付宝** —— 安卓的通知监听按用户空间隔离，
> App 收不到另一个空间的通知（真机已确认）。

> 如果 4.1 没自动出现：先看 **设置 → 第 1 项** 是不是显示「已授权·未连接」，
> 是的话把系统开关关掉再打开。**注意：微信/支付宝的「转账」通知里没有金额，
> 那种支付本来就记不上**（见 [真机验收记录](真机验收记录.md)），请改用扫码付款给商家。

## 附：已知限制（不是 bug，不用报）

1. **后台被系统冻结后收不到通知** —— Android 层面限制，所有通知类记账 App 都一样。
   App 的应对：打开一次即自动重连。设置页会显示黄色警告提示你。
2. **微信/支付宝措辞随版本变化** —— 内置规则覆盖常见格式，遇到新的用「自定义规则」当场加，不用等更新。
3. **release 包用的是调试签名** —— 手机上会提示「未知来源应用」，功能完全一样。
