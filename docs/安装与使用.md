## 二、安装 Android Studio

### 1. 下载

打开 https://developer.android.com/studio

点绿色的 **Download Android Studio** 按钮，勾选同意条款，下载 Windows 版
（文件名类似 `android-studio-2024.x.x-windows.exe`，约 1.2 GB）。

> 如果官网打不开或下载很慢，国内可以用镜像站，但版本可能略旧，尽量用官网。

### 2. 安装

双击下载的 exe，一路下一步：

- 安装类型选 **Standard**（标准）
- 安装路径**别用中文、别用空格**，保持默认的 `C:\Program Files\Android\Android Studio` 最省事
- 到了 **License Agreement** 页面，会列出好几条协议，每条都要点 **Accept**
  （这是唯一需要你手动多点几下地方，别漏了）

点 Finish，等它装完。

### 3. 首次启动向导

第一次打开 Android Studio 会弹一个 Setup Wizard：

1. **Install Type** → 选 **Standard**
2. **Verify Settings** → 它会显示要下载的组件，包括：
   - Android SDK Platform（安卓开发包）
   - Android SDK Build-Tools
   - Android Emulator（模拟器，**可以不要**，我们用真机）
3. 点 **Next** → **Accept** 所有协议 → **Finish**

然后它开始下载 SDK，**这一步最慢**，几个 G，视网速可能 20 分钟到 2 小时。
进度条在底部。下载完点 Finish。

## 四、装完后必须做的三步授权

> ⚡ **2026-10-15 起不用自己去找了**：每次打开 App，它都会自动检测
> 通知权限、后台运行权限、短信、通知使用权这四项，缺哪项就直接弹出
> 对应的系统对话框（或帮你跳到系统开关列表）。你要做的只是点「允许」。
> 下面这三步是「弹窗分别是什么、怎么点」的说明。

App 打开后（或点右上角 **⚙️ 设置**），会看到三个权限项：

### 1. 通知使用权（必须，不做则完全不能自动记账）

打开 App 时如果没开，App 会**直接跳**到系统的「通知使用权」列表
→ 找到 **流水记账** → 打开开关 → 弹窗警告「将读取所有通知」→ 点 **允许**

> ⚠️ 这是 Android 的硬性限制，**任何记账 App 都绕不过这一步**，
> App 自己弹不出这个授权框，只能帮你跳到开关页面。

### 2. 短信权限（推荐）

打开 App 时如果没给，会直接弹出系统授权框，点 **允许** 即可，
不用自己去设置里找。

### 3. 关闭电池优化（强烈建议）

打开 App 时如果没关，会弹出系统的「是否允许忽略电池优化」对话框，
点 **允许**。

> 拒绝一次没关系，下次打开 App 会再问一次；四项全给齐之后，
> App 不再弹任何东西。

### 额外：国产 ROM 的保活设置（很重要）

不做这一步，App 会在几小时后被系统杀掉，导致漏记。

| 品牌 | 操作路径 |
|---|---|
| **小米/红米** | 设置 → 应用设置 → 应用管理 → 流水记账 → 省电策略 → **无限制**；<br>再在「最近任务」界面下拉这个 App → 点🔒**加锁** |
| **华为/荣耀** | 设置 → 应用 → 应用启动管理 → 流水记账 → 关闭「自动管理」→ 手动管理里**三项全开** |
| **OPPO/一加** | 设置 → 电池 → 应用耗电管理 → 流水记账 → 允许**后台运行** |
| **vivo** | 设置 → 电池 → 后台高耗电 → 允许流水记账 |
| **三星** | 设置 → 电池 → 后台使用限制 → 把流水记账加入「永不进入休眠的应用」 |

**还有一条**：以后**不要在最近任务里划掉这个 App**，划掉 = 关掉服务。

## 六、常见报错处理

### 「Gradle sync failed」/ 一直卡在下载

国内网络访问 Google 的 Maven 仓库经常超时。等一会儿重试，
或者挂代理。这是网络问题，不是代码问题。

### 「SDK location not found」

Android Studio 没装好 SDK。菜单 **Tools → SDK Manager**，
确保 **Android 14.0 (API 34)** 已勾选并安装。

### 「Unsupported Java version」

Android Studio 自带的 JDK 版本不对。菜单
**File → Settings → Build, Execution, Deployment → Build Tools → Gradle**，
把 **Gradle JDK** 改成 **jbr-17**（Android Studio 自带的那个）。

### 手机连不上 / 显示 No Devices

1. 换一根**能传数据**的 USB 线
2. 手机开发者选项里试试点「撤销 USB 调试授权」，然后重新插拔
3. 手机上把 USB 连接模式从「仅充电」改成「传输文件」

### App 装上后不自动记账

按顺序排查：
1. 设置页里「通知使用权」是不是**已开启**？（关掉重开一次试试）
2. 有没有在最近任务里把 App 划掉？
3. 电池优化关了没？
4. 用「解析测试」确认规则能识别你的通知格式

## 七、日常使用

### ⚠️ 最重要的一条：记账"不灵"了怎么办

这是这个 App **最需要注意的地方**，请务必读完。

「通知使用权」在设置里显示**已开启**，并不代表 App 真的在收通知。
系统会在下面这些情况下**悄悄把监听服务解绑**，此时授权照旧显示已开启，
但 App **一条通知都收不到，而且不会报错**：

- 手机内存紧张时系统自动回收后台进程
- 长时间没打开过这个 App
- 在「最近任务」里把它划掉
- 某些 ROM 的省电策略

**表现**：你付了钱，但流水列表里没出现记录。

#### 怎么发现

打开 App → 右上角 **⚙️ 设置** → 看第 1 项：

| 显示 | 含义 |
|---|---|
| **已开启** | 监听正常，放心用 |
| **已授权·未连接** | ❌ **掉线了**，现在收不到任何通知 |

#### 怎么恢复（真机实测唯一有效的一条）

**去系统设置里，把「通知使用权」的开关关掉，再重新打开。**

1. 在设置页点第 1 项下面的 **「去把开关关掉再打开」** 按钮
2. 找到 **流水记账** → 把开关**关掉**
3. 等 2 秒 → **再打开**
4. 返回 App，状态变回 **已开启** 就好了

> ⚠️ 实测提醒：**光把 App 打开一次是不够的**，这条旧说法已被真机验证推翻。
> App 内置了 60 秒一次的自动重连尝试，但部分 ROM（尤其小米）会忽略它，
> 所以上面这个手动步骤请你记住 —— 出现「已授权·未连接」就这么做。

**养成习惯**：每天打开一次，顺手看一眼设置页第 1 项的状态。
如果发现漏记了，按上面步骤恢复，漏掉的那几笔用 ＋ 号手动补录，
或者用「导入账单」一次性补回来。

> 这是 Android 系统层面的限制，**所有依赖通知的记账 App 都一样**，
> 不是本 App 的实现缺陷。

| 我想做的事 | 怎么做 |
|---|---|
| 看流水 | 打开 App，首页就是，按天分组，最新的在最上面 |
| 补一笔现金消费 | 点右下角 **＋**，填金额和备注 |
| 改一笔记错的 | 点那条记录，改完保存 |
| 删一笔 | 点那条记录 → 左下角「删除」 |
| 看原始通知文本 | 点记录，弹窗底部会显示「原始文本」 |
| 确认监听是否正常 | 打开 **设置**，看第 1 项有没有黄色警告 |

## 八、这个版本有什么、没有什么

**有：**
- 自动抓取微信/支付宝/银行的通知和短信
- 自动判断收入还是支出
- 重复记录自动去重（同一笔钱通知+短信都来了，只记一次）
- **朋友间转账的「待确认」补录**（转账通知里没有金额，App 提醒你补一下）
- 手动补录、编辑、删除
- 按天分组、月度汇总
- 解析测试工具（用来调规则）
- **导入支付宝/微信 CSV 账单**（补漏，并自动与已记流水去重）

**暂时没有（按你的要求后续再加）：**
- 消费分类（账单导入时会保留支付宝的类型字段）
- 预算和提醒
- 图表报表
- 云同步

数据全部存在手机本地，不联网，不上传。

## 九、导入账单（可选功能）

如果你担心漏记，可以用这个功能补。**入口：设置 → 导入账单**。

### 怎么导出

| 平台 | 路径 |
|---|---|
| **支付宝** | 我的 → 账单 → 右上角「···」→ 开具交易流水证明 → 用于个人对账 |
| **微信** | 我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 用于个人对账 |

两家都会把 CSV 发到你邮箱。**微信发的是加密压缩包，需要密码解压**
（密码在邮件里）。

### 重要：不用管重复

导入时会自动和已有流水去重：

- 通知**已经记过**的 → 自动跳过，不会记两次
- 通知**漏掉**的 → 补上

所以你可以放心地「装完 App 先跑几天，再导入一份完整账单」，
不会出现重复。而且同一份账单导入两次也不会重复。

### 注意

- 必须是**邮箱里下载的原始 CSV**。用 Excel 打开再另存会改列名，导致解析失败。
- 支付宝账单是 GBK 编码，App 会自动识别（UTF-8/GBK 都会试）。

## 十、发现漏记/记错怎么办（重要）

### 第一步：先确认监听还活着

打开 **设置**，看第 1 项「通知使用权」的状态：

- 显示 **已开启** → 监听正常，往下走第二步
- 显示 **已授权·未连接** → ❌ 掉线了，去系统设置里**把开关关掉再打开**（见第七节）

### 第二步：自己加一条规则（不用等我）

App 内置了规则编写工具，**遇到认不出的格式你可以自己解决**，
不用等 App 更新，也不用重新安装。

打开 **设置 → 自定义规则**：

1. **起个名字**，比如「招商银行短信」
2. **写正则** —— 关键是把金额用括号括起来：
   ```
   源文本：您账户1523于11月01日21:05扣款人民币99.50，余额1123.59
   正则：  扣款人民币([\d,]+\.?\d*)
   ```
   `([\d,]+\.?\d*)` 这段就是「抓取金额」的意思，照抄即可
3. **金额在第几个括号**：默认 1，如果你写了多个括号就填对应序号
4. **选支出还是收入**
5. **粘贴原文测试** —— 会立刻告诉你能不能匹配、抓到多少钱
6. **保存** —— 立即生效

页面里有正则速查表，照着改就行。

### 第三步：实在搞不定就发给我

设置 → **导出样本** → 分享 → 发给我。我会补进内置规则。

> **这两条路你选一条即可。** 自己写规则的好处是立刻生效；
> 发给我的好处是下次更新后所有人都能用上。

### 关于隐私

- 只留档「和钱有关」的通知（含金额、收支、支付等字样）
- **验证码、聊天记录、普通推送不会被记录**
- 最多保留最近 300 条，自动淘汰旧的
- 随时可以点「清空全部样本」
- 数据只在手机本地，不上传

导出的内容长这样，可以直接复制给我：

```
流水记账 — 通知样本导出
共 3 条
==================================================

[UNMATCHED]
包名: com.xxx.bank
时间: 2026-10-14 16:42:03
原文: 【某某银行】您尾号9999的卡发生一笔金额为66.00元的交易
```

我看到 `[UNMATCHED]` 的样本就能直接写正则补上规则。

## 十一、朋友间转账怎么记（「待确认转账」）

### 为什么需要这一步

**微信/支付宝给好友转账后，推到通知栏的那条消息里没有金额**，
原文只有「[转账]已被接收」这样的文案。金额只存在于微信内部的账单页面里，
通知拿不到。

所以你和朋友之间的转账，App 抓不到金额 —— 这不是 bug，
是数据源本身缺字段。以前这种通知会被直接丢掉（你会漏记），
现在改成**「待确认」**：App 知道有这笔转账，只是需要你补一个金额。

### 你会看到什么

转账完大约几秒内，会出现**两条**提醒：

1. **通知栏**：一条「检测到一笔微信转账」的通知
2. **App 首页**：月度汇总下面一条橙色的「待确认转账」卡片

### 怎么操作（大约 3 秒）

**最快的方式：不打开 App，在通知里直接填。**

1. 点通知上的 **「填入金额」** 按钮
2. 金额框在通知里展开，**直接输入数字**
3. （可选）点一下「支出/收入」—— 不选就按默认方向
4. 点发送 ✅ 完成，顺手有一条回执通知告诉你记上了

金额输错了（比如把「38.50」输成「38」）也没事：在流水列表里点那条记录就能改。

**或者用老方式**：点通知正文 / 首页卡片 → 打开补录弹窗
（弹窗自动聚焦在金额输入框，数字键盘直接弹出来）→ 输入金额 → 点「记账」→ 完成。

方向、对方、备注都可以不填：
- **方向**已经按通知文案猜了一个（默认「支出」，不对就直接点另一个）
- 想填对方和备注就填，不填也能存

### 「不是转账」按钮

如果 App 把一条不是转账的通知误判成了转账（比如营销短信里出现了「转账」二字），
有两个地方可以打发它：

- **通知栏**：直接点通知上的「不是转账」按钮，不用打开 App
- **首页卡片**：点「不是转账」按钮

### 常见疑问

**问：为什么方向默认是「支出」？**

微信对转账**双方**推的是同一句「[转账]已被接收」，
所以从文案上分不清是你转出还是别人转你。

默认给「支出」，是因为日常主动转出比被动收款更常见，且**方向必须明确** ——
这个 App 只有「支出」和「收入」两个方向，没有「中性」这种中间态。
（早期版本有「中性」，但它在统计上等于没记：月度支出和收入两个数字都不动，
用户会以为 App 又没记上。方向说不清时更该让你自己选，而不是记一个模糊值。）

如果默认方向不对，在弹窗里点一下另一个就行，之后也能在流水列表里改。

**问：我转账后没收到提醒？**

按顺序检查：
1. 有没有给 App 通知权限（设置 → 应用 → 流水记账 → 通知）
2. 首页有没有「待确认转账」卡片（有的话说明抓到了，只是通知没弹出来）
3. 是不是用了**应用分身/双开**的微信 —— 分身属于另一个用户空间，
   通知监听收不到（见第八节）

**问：会不会漏记？**

「待确认」记录存在数据库里，**不会因为 App 被杀掉而消失**。
最坏情况是你当时没看到提醒，下次打开 App 时首页卡片还在。

> 注意：如果转账通知里的金额本来就抓不到，而你又长期不处理，
> 待确认记录最多保留 50 条，最旧的会被自动清掉。建议顺手处理掉。
