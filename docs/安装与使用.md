# 流水记账 — 从零开始安装到手机

> ## ⚡ 先看这里：你可以不用装 Android Studio
>
> **APK 已经编译好了**，就在这个位置：
>
> ```
> D:\Accounting tool\交付物\流水记账-v0.1.0.apk
> ```
>
> （原始产物在 `app\build\outputs\apk\release\app-release.apk`，两个是同一个文件）
>
> 把这个文件传到手机（微信发给自己 / 数据线拷贝 / 网盘都行），
> 在手机上点开安装即可。**大约 2 分钟搞定**，跳过下面全部一~三节，
> 直接看 **第四节：装完后必须做的三步授权**。
>
> 安装时手机会提示「未知来源应用」，允许即可 —— 因为这个 APK 用的是
> 调试签名，不是应用商店的正式签名。功能完全一样。
>
> 如果手机上提示「解析包错误」或装不上，通常是 Android 版本低于 8.0，
> 这时再考虑下面的自行编译方案。
>
> **什么时候才需要装 Android Studio？**
> 只有当你想要**修改代码**（比如换配色、加功能、改识别规则）时才需要。
> 只是日常使用，装 APK 就够了。

这份文档假设你**从没装过 Android 开发环境**。跟着做就行，全程约 40 分钟，
其中大部分时间是电脑在下载东西，你只需要等。

## 一、你要装的东西（只有两样）

| 软件 | 作用 | 大小 | 是否收费 |
|---|---|---|---|
| **JDK 17** | Java 运行环境，Android 编译必需 | 约 200 MB | 免费 |
| **Android Studio** | 写代码 + 编译打包的软件 | 约 1.2 GB（装完占 8~10 GB） | 免费 |

> Android Studio 安装包**自带 JDK**，正常情况下你**不用单独装 JDK**。
> 如果后面报错说找不到 Java，再按第五节的「常见报错」处理。

## 二、安装 Android Studio

### 1. 下载

打开 https://developer.android.com/studio

点绿色的 **Download Android Studio** 按钮，勾选同意条款，下载 Windows 版
（文件名类似 `android-studio-2024.x.x-windows.exe`，约 1.2 GB）。

> 如果官网打不开或下载很慢，国内可以用镜像站，但版本可能略旧，尽量用官网。

### 2. 安装

双击下载的 exe，一路下一步：

- 安装类型选 **Standard**（标准）
- 安装路径**别用中文、别用空格**，保持默认的 `C:\Program Files\Android\Android Studio` 最省事
- 到了 **License Agreement** 页面，会列出好几条协议，每条都要点 **Accept**
  （这是唯一需要你手动多点几下地方，别漏了）

点 Finish，等它装完。

### 3. 首次启动向导

第一次打开 Android Studio 会弹一个 Setup Wizard：

1. **Install Type** → 选 **Standard**
2. **Verify Settings** → 它会显示要下载的组件，包括：
   - Android SDK Platform（安卓开发包）
   - Android SDK Build-Tools
   - Android Emulator（模拟器，**可以不要**，我们用真机）
3. 点 **Next** → **Accept** 所有协议 → **Finish**

然后它开始下载 SDK，**这一步最慢**，几个 G，视网速可能 20 分钟到 2 小时。
进度条在底部。下载完点 Finish。

## 三、把项目跑起来

### 1. 打开项目

Android Studio 欢迎页点 **Open**，选择这个文件夹：

```
D:\Accounting tool
```

⚠️ 注意选的是**文件夹本身**，不是里面的某个文件。

首次打开会自动开始 **Gradle Sync**（右下角有进度条）。
第一次同步要下载 Gradle 和一堆依赖库，又是几个 G，**耐心等**。
如果弹出提示问是否 Trust Project，点 **Trust**。

### 2. 手机准备

**在手机上操作：**

1. 打开 **设置 → 关于手机**
2. 连续点击 **版本号** 7 次，直到提示「您已处于开发者模式」
3. 返回 **设置 → 系统 → 开发者选项**
4. 打开 **USB 调试**
5. 用数据线连电脑，手机弹出「允许 USB 调试吗？」→ 点 **允许**（勾选「一律允许」）

> 小米：开发者选项在「设置 → 更多设置」里
> 华为：设置 → 系统和更新 → 开发人员选项

**注意**：有些数据线只能充电不能传数据，如果电脑认不到手机，换根线试试。

### 3. 编译安装

Android Studio 顶部工具栏：

1. 确认设备下拉框里显示你的手机型号（不是 "No Devices"）
2. 点绿色三角形 **▶ Run**
3. 等它编译（第一次 3~10 分钟），然后手机上会自动装上并打开

**装好了。**

## 四、装完后必须做的三步授权

App 打开后，点右上角 **⚙️ 设置**，会看到三个权限项：

### 1. 通知使用权（必须，不做则完全不能自动记账）

点「去开启」→ 跳到系统的「通知使用权」列表 → 找到 **流水记账** → 打开开关
→ 弹窗警告「将读取所有通知」→ 点 **允许**

> ⚠️ 这是 Android 的硬性限制，**任何记账 App 都绕不过这一步**，
> 必须你手动开，App 自己申请不了。

### 2. 短信权限（推荐）

点「去开启」，在应用权限页里允许 **短信**。

### 3. 关闭电池优化（强烈建议）

点「去关闭」，在弹窗里选 **允许**。

### 额外：国产 ROM 的保活设置（很重要）

不做这一步，App 会在几小时后被系统杀掉，导致漏记。

| 品牌 | 操作路径 |
|---|---|
| **小米/红米** | 设置 → 应用设置 → 应用管理 → 流水记账 → 省电策略 → **无限制**；<br>再在「最近任务」界面下拉这个 App → 点🔒**加锁** |
| **华为/荣耀** | 设置 → 应用 → 应用启动管理 → 流水记账 → 关闭「自动管理」→ 手动管理里**三项全开** |
| **OPPO/一加** | 设置 → 电池 → 应用耗电管理 → 流水记账 → 允许**后台运行** |
| **vivo** | 设置 → 电池 → 后台高耗电 → 允许流水记账 |
| **三星** | 设置 → 电池 → 后台使用限制 → 把流水记账加入「永不进入休眠的应用」 |

**还有一条**：以后**不要在最近任务里划掉这个 App**，划掉 = 关掉服务。

## 五、验证是否成功

### 方法一：真实支付测试

用微信或支付宝**付一笔小钱**（比如给朋友转 0.01 元），
回到「流水记账」，看首页有没有自动出现这笔记录。

### 方法二：解析测试（推荐先用这个）

点 **设置 → 解析测试**，把一条真实的支付通知文本粘进去，点「测试识别」。

- 显示「✅ 识别成功」并给出金额 → 规则工作正常
- 显示「⚠️ 未识别出金额」→ **把这条原文发给 AI**，让它加规则

> 想拿到通知原文：支付后下拉通知栏，长按那条通知 → 复制文本。
> 或者截图发给我，我来读。

## 六、常见报错处理

### 「Gradle sync failed」/ 一直卡在下载

国内网络访问 Google 的 Maven 仓库经常超时。等一会儿重试，
或者挂代理。这是网络问题，不是代码问题。

### 「SDK location not found」

Android Studio 没装好 SDK。菜单 **Tools → SDK Manager**，
确保 **Android 14.0 (API 34)** 已勾选并安装。

### 「Unsupported Java version」

Android Studio 自带的 JDK 版本不对。菜单
**File → Settings → Build, Execution, Deployment → Build Tools → Gradle**，
把 **Gradle JDK** 改成 **jbr-17**（Android Studio 自带的那个）。

### 手机连不上 / 显示 No Devices

1. 换一根**能传数据**的 USB 线
2. 手机开发者选项里试试点「撤销 USB 调试授权」，然后重新插拔
3. 手机上把 USB 连接模式从「仅充电」改成「传输文件」

### App 装上后不自动记账

按顺序排查：
1. 设置页里「通知使用权」是不是**已开启**？（关掉重开一次试试）
2. 有没有在最近任务里把 App 划掉？
3. 电池优化关了没？
4. 用「解析测试」确认规则能识别你的通知格式

## 七、日常使用

### ⚠️ 最重要的一条：记账"不灵"了怎么办

这是这个 App **最需要注意的地方**，请务必读完。

Android 系统会在以下情况**把后台进程冻结**，此时「通知使用权」在设置里
依然显示为**已开启**，但 App **实际收不到任何通知**，而且不会报错：

- 手机内存紧张时系统自动回收后台进程
- 长时间没打开过这个 App
- 在「最近任务」里把它划掉
- 某些 ROM 的省电策略

**表现**：你付了钱，但流水列表里没出现记录。

**解决办法**：**打开一次 App**。

App 每次回到前台都会主动请求重新连接系统通知监听，
所以「打开一下」就能自动恢复，不需要重新授权。

**养成习惯**：每天打开一次看一眼。如果发现漏记了，
打开一次就能恢复，漏掉的那几笔用 ＋ 号手动补录。

> 这是 Android 系统层面的限制，**所有依赖通知的记账 App 都一样**，
> 不是本 App 的实现缺陷。只能靠「打开一次」来绕过。

| 我想做的事 | 怎么做 |
|---|---|
| 看流水 | 打开 App，首页就是，按天分组，最新的在最上面 |
| 补一笔现金消费 | 点右下角 **＋**，填金额和备注 |
| 改一笔记错的 | 点那条记录，改完保存 |
| 删一笔 | 点那条记录 → 左下角「删除」 |
| 看原始通知文本 | 点记录，弹窗底部会显示「原始文本」 |
| 确认监听是否正常 | 打开 **设置**，看第 1 项有没有黄色警告 |

**有：**

- 自动判断收入还是支出

- 解析测试工具（用来调规则）

## 九、导入账单（可选功能）

如果你担心漏记，可以用这个功能补。**入口：设置 → 导入账单**。

### 怎么导出

| 平台 | 路径 |
|---|---|
| **支付宝** | 我的 → 账单 → 右上角「···」→ 开具交易流水证明 → 用于个人对账 |
| **微信** | 我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 用于个人对账 |

两家都会把 CSV 发到你邮箱。**微信发的是加密压缩包，需要密码解压**
（密码在邮件里）。

### 重要：不用管重复

导入时会自动和已有流水去重：

- 通知**已经记过**的 → 自动跳过，不会记两次
- 通知**漏掉**的 → 补上

所以你可以放心地「装完 App 先跑几天，再导入一份完整账单」，
不会出现重复。而且同一份账单导入两次也不会重复。

### 注意

- 必须是**邮箱里下载的原始 CSV**。用 Excel 打开再另存会改列名，导致解析失败。
- 支付宝账单是 GBK 编码，App 会自动识别（UTF-8/GBK 都会试）。

## 十、发现漏记/记错怎么办（重要）

### 第一步：先确认监听还活着

打开 **设置**，看第 1 项「通知使用权」有没有黄色警告。
如果有 → 退出重进一次即可恢复（见第七节）。

### 第二步：自己加一条规则（不用等我）

App 内置了规则编写工具，**遇到认不出的格式你可以自己解决**，
不用等 App 更新，也不用重新安装。

打开 **设置 → 自定义规则**：

1. **起个名字**，比如「招商银行短信」
2. **写正则** —— 关键是把金额用括号括起来：
   ```
   源文本：您账户1523于11月01日21:05扣款人民币99.50，余额1123.59
   正则：  扣款人民币([\d,]+\.?\d*)
   ```
   `([\d,]+\.?\d*)` 这段就是「抓取金额」的意思，照抄即可
3. **金额在第几个括号**：默认 1，如果你写了多个括号就填对应序号
4. **选支出还是收入**
5. **粘贴原文测试** —— 会立刻告诉你能不能匹配、抓到多少钱
6. **保存** —— 立即生效

页面里有正则速查表，照着改就行。

### 第三步：实在搞不定就发给我

设置 → **导出样本** → 分享 → 发给我。我会补进内置规则。

> **这两条路你选一条即可。** 自己写规则的好处是立刻生效；
> 发给我的好处是下次更新后所有人都能用上。

### 关于隐私

- 只留档「和钱有关」的通知（含金额、收支、支付等字样）
- **验证码、聊天记录、普通推送不会被记录**
- 最多保留最近 300 条，自动淘汰旧的
- 随时可以点「清空全部样本」
- 数据只在手机本地，不上传

导出的内容长这样，可以直接复制给我：

```
流水记账 — 通知样本导出
共 3 条
==================================================

[UNMATCHED]
包名: com.xxx.bank
时间: 2026-10-14 16:42:03
原文: 【某某银行】您尾号9999的卡发生一笔金额为66.00元的交易
```

我看到 `[UNMATCHED]` 的样本就能直接写正则补上规则。
